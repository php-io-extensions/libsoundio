# Agent guidance — php-io-extensions/libsoundio

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1 at the libsoundio 2.0 API, all 72 functions.** Function and constant names are the C names. No defaults, no composites, no glue beyond what `bindings.json` lists. A need of code built on the extension is solved in that code, not here.
3. **Translations, the only ones.** A handle struct is a handle class; its C fields are live properties (`readonly` where libsoundio fills them). The three value structs are copied objects. An out-parameter is by-reference. A list libsoundio takes with a count is a PHP list and keeps the count as its own parameter. A buffer address, channel area `ptr`, `userdata` and every callback libsoundio calls off the PHP thread are `int` addresses. Failure is the C error code.
4. **Handles.** `SoundIo`, `SoundIoDevice`, `SoundIoOutStream`, `SoundIoInStream`, `SoundIoRingBuffer`: `final`, private `__construct`, not cloneable, not serializable, `pointer(): int` (0 once released), `static fromPointer(int $pointer): ?static` (null for 0). One PHP object per native pointer (`libsoundio_box`). `soundio_destroy`, `soundio_outstream_destroy`, `soundio_instream_destroy` and `soundio_ring_buffer_destroy` release theirs; `soundio_device_unref` releases the device when that reference was its last. A released handle is NULL. Where libsoundio takes NULL, the NULL goes to libsoundio. Elsewhere it dereferences it, so the extension refuses it (site `libsoundio-released-handle`).
5. **Callbacks.** Only `on_devices_change` and `on_backend_disconnect` are PHP (`?Closure`), held in `LIBSOUNDIO_G(callouts)` per `SoundIo` and entered only inside `soundio_flush_events` / `soundio_wait_events` on the PHP thread. Every other callback field is an address: never run PHP on libsoundio's audio or JACK threads. RSHUTDOWN gives every struct back libsoundio's own callbacks, then frees the callables.
6. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. `@param list<…>` breaks gen_stub; describe lists in prose.
7. **Refusals are proven.** A site is kept only when its `tests/Probes` off-run crashes the process on a probe build. Every throw carries `/* binding:<id> */` naming a site in `bindings.json`.
8. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`. On the Pi, copy the tree with `fnk` and `./install-debian-trixie.sh`. Pest at `-d memory_limit=128M`. Tests use `SoundIoBackendDummy`: never connect a real backend in a test, it makes sound. Gate a commit on the suite's exit code.
9. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`. After a binding change run `php84 scripts/support.php`.
10. **Version** is `PHP_LIBSOUNDIO_VERSION` in `php_libsoundio.h`: 0.11.0. `os-families`: linux, darwin.
